Review: Report Text Structure

1. Identification

Mengenalkan objek secara umum.

Contoh: The Bekantan is a monkey with a long nose.

The Cenderawasih is a beautiful bird.

2. Description

Menjelaskan ciri fisik, habitat, makanan, perilaku.

Contoh: It has reddish-brown fur. It lives in Borneo. It eats leaves.

Review: Grammar untuk Report

1. To Be: is / are / am

The Bekantan is a monkey.

2. Has / Have: untuk kepemilikan

It has a long nose. They have long arms.

3. Simple Present: untuk fakta

It lives in Borneo. It eats leaves.

4. Possessive: its / their

Its fur is brown. Their habitat is Borneo.

5. Passive Voice: to be + verb-3

Bekantans are found in Borneo.

Susun Kalimat!

Gunakan outline-mu untuk membuat kalimat.

Pola kalimat:

• Identification: The [hewan] is a [jenis hewan].

• Ciri fisik: It has [ciri fisik].

• Habitat: It lives in [habitat].

• Makanan: It eats [makanan].

• Fakta unik: It is [fakta unik].

Contoh Report Text — Orangutan

1The orangutan is a big ape. (Identification)🔊

2It has long arms and reddish hair.🔊

3It lives in the forests of Borneo and Sumatra.🔊

4It eats fruit, leaves, and insects.🔊

5It is very smart and can use tools.🔊

6Orangutans are found in Borneo and Sumatra. (Passive)🔊
